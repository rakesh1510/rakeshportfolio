# Rakesh Portfolio (Multi-page, Responsive, EN/DE toggle)

## Language switch
- Top-right button shows **DE** or **EN**
- Click it to switch language (English/German)
- Preference is saved in the browser (localStorage)

## Footer
Footer is injected from `assets/footer.html` on every page to keep it identical.

## Hosting
Upload all files to your server. For local testing, use a simple server:
- PHP built-in: `php -S localhost:8000` (recommended so contact.php works)
